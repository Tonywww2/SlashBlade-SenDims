# 世界树海结构更新：装饰、战斗与入口

维度：`sdbf:deep_realm_level_2`。重启游戏后在新生成区块生效。

## 装饰与英文文本

6 类小型结构和 3 类地牢，共 117 个模板，使用批准的 22 种装饰方块。排除全部深暗之园方块。实验室保留 Quark 铁板外壳；木屋使用古橡木、活木饰面、茅草屋顶、纸灯和绳索；旧廊使用暮色森林旧砖/扭曲石柱；研究室加入装饰管道、通风板、格栅、工业灯和白色瓷砖。

原有告示牌全部替换为 `pneumaticcraft:aphorism_tile`（64 处），使用实际 `ExtraData.lines` 文本格式，朝向按其靠墙方向设置。标识、提示和研究日志统一为英文。静态预览没有绘制警句板的动态文字，实际 Forge 方块实体保存/读取已验证。

## 入口与楼梯

- 悬冠聚落：三格宽自适应栈道，尽端连接实木枝面；支撑向下接枝，护栏沿高差连续铺设。
- 枯心回廊：五格宽地表引道，五段三格宽折返楼梯和宽转角平台。地下两处楼层变化也采用真实楼梯方块。
- 沉根观测枢纽：水下登舱平台、双铁舱口气闸、两段三格宽铁板楼梯，最后以短梯连接气闸。仍需关闭上口、用桶排空夹层后再开下口。
- 接道位置在模板预留范围内；写入按当前区块裁剪，拒绝超出合理高差或头顶被实木挡住的位置。新增接道数据和支撑位置可保存/重载。
