# 客户端启动优化实现与验证

本轮已在 SlashBlade SenDims 项目实现并启用启动优化，验收范围为 JVM 启动至可用主菜单。OBJ 准备使用有上限的并行任务，与其他资源准备重叠；解析结果可以跨启动保存在磁盘。最终对照只测试启动，不触发手动资源重载，不进入存档。

关闭和开启使用同一份最终 JAR，只切换 `sendims.startup.enabled`。JVM、其他模组、资源包、光影配置、动态光源与已有每帧渲染优化保持一致。两次均使用已有磁盘与系统文件缓存；这是缓存命中后的单组结果，不能推导首次安装耗时或长期平均收益。

本组总启动耗时减少 **4.777 秒，即 4.32%**。该差值包含所有本组开关的组合效果，没有逐项关闭采样，不能把它拆成各个优化分别节省的秒数。此前 8～15 秒属于工程预估，不能视为已兑现的测试结果。

堆使用是主菜单稳定约 2 秒后的单点读数，不是峰值、最低值或平均值。GC 计数覆盖 JVM 启动至该快照；ZGC 的并发回收累计时间不是停顿时间。当前结果不足以认定稳定的内存或 GC 降幅。

开启时记录 OBJ 解析 0 次、磁盘命中 137 次、原解析器回退 0 次。关闭与开启加载的全部 136 个模型摘要相同，覆盖顶点、UV、法线、分组、面顺序、索引共享关系与面法线浮点位。摘要为 `6821e11cf39b7497fa54077f54fb971ae86080d51f06cf490856a871b586256c`。

## 实现内容

| 方向 | 已实现行为 | 边界与配置 |
| --- | --- | --- |
| Mixin 操作码名称查询 | 将重复反射查询替换为常量分支表，复用已安装的 Instrumentation | `opcodeNameCache`；只识别已审计的方法结构，未知版本或无现成 Agent 时保持原流程，不新增 Agent 或 JVM 参数 |
| SlashBlade OBJ 解析 | 使用字符扫描和数字分词，减少逐行正则、split 与临时数组 | `objParser`；未知语法和超大输入完整回退，保留原异常行为 |
| OBJ 并行准备 | 资源枚举和解析交给现有准备线程池，默认最多 4 个工作任务；准备完成后通过游戏屏障，由应用线程发布模型 | `parallelObjPreparation`、`objWorkers`；工作线程不等待同池子任务，不执行 GL 操作，不共享可变模型对象 |
| OBJ 磁盘缓存 | 按实际模型字节、字符集与解析器版本作 SHA256 键；压缩、缓冲读写、原子替换 | `objDiskCache`、`objCacheMiB`；默认磁盘预算 128 MiB，损坏或过期条目按未命中处理，原资源包优先级保留 |
| 普通模型输入 | 保留原 JSON 解析器和资源包叠加顺序，将逐文件 Future 改为有上限的批次任务 | `modelInputBatches`、`modelWorkers`；默认每类最多 8 个任务，仍使用游戏提供的线程池 |
| 模型地址重复构造 | 在一次模型准备的生命周期内复用相同方块状态对应的模型地址 | `modelLocationCache`、`modelLocationEntries`；默认最多 262144 项，准备结束释放映射及其容量 |
| 配置界面动画预览 | 首次启动暂缓 Sounds 的 WebP 与 GIF 配置预览，由 YACL 原生路径在打开时按需加载 | `lazyConfigImages`；任务 HUD 图片继续预载，首次启动后保持原资源生命周期 |

OBJ 缓存仅保存中间数据。每次加载重新构造可变的 Vertex、Face 与 GroupObject，不额外保留一套永久堆内模型缓存。异步写入只有一个低优先级线程，队列最多 128 项，待写数据最多 32 MiB，空闲 10 秒后线程退出；单条解压数据限制 32 MiB。当前缓存 129 个文件，共 16.04 MiB，无遗留临时条目。

原解析器含共享 Matcher，不能直接并发调用。新解析器不共享这些状态；回退路径使用单独锁串行执行。模型加载完成后一次发布完整缓存，其他准备工作可以继续执行，最后应用阶段仍遵守游戏要求的同步屏障。

普通 JSON 模型解析原本已支持并行。本轮主要限制任务数量并减少重复构造；没有把可变的 BlockModel 或自定义 BakedModel 跨启动持久化，也没有强行并行烘焙。现有 Lightspeed 模型输入快照只按包标识判断一致性，无法充分检测同包内内容变化，因此没有开启该快照。Lightspeed 和 Smooth Boot 的全局线程数保持原配置。

早期 JAR 文件系统方向完成了生命周期审计，未增加跨实例共享缓存。当前 UnionFileSystem 会拥有并关闭内部文件系统，直接共享可能破坏其他实例；特供模组的常规加载阶段也晚于被测的早期模块解析。OBJ 加载复用枚举时得到的 Resource，避免重新全局查找，但这不能算作早期 Forge 模块启动加速。

## 配置与回退

配置文件为 [slashblade_sendims.toml](C:/Users/Tony/AppData/Roaming/PrismLauncher/instances/SenDimsBanForges/minecraft/config/slashblade_sendims.toml)。启动选项位于 `[startup]`，其中所有布尔开关当前为 true，修改后重启生效。设置 `enabled=false` 关闭启动优化整组；也可单独关闭各项。`objParser=false` 同时关闭依赖它的并行准备和磁盘缓存。`objWorkers=0` 与 `modelWorkers=0` 使用上述自动上限，`objCacheMiB=0` 停止缓存读写。
